# 📖 About the Project

**CollegeGPT – Smart College Management & Student Service Platform** is a centralized digital platform developed to improve the way students, visitors, and college administrators interact with college services.

Traditional college management often involves multiple disconnected processes such as:

* Manual admission forms
* Physical notice boards
* Separate student service systems
* Manual grievance handling
* Offline event registration
* Manual hostel requests
* Difficult access to college information
* Repetitive student queries to college staff

CollegeGPT brings these services together into a single web-based platform.

The system is not only an AI chatbot. It is a **complete full-stack college management and student service platform**. The AI-powered **CollegeGPT assistant is one of the intelligent modules integrated into the system**, helping users quickly access and understand college-related information.

In many colleges, students need to visit different departments for different services.

For example:

# 🧠 AI & CollegeGPT Module

The AI functionality is based on a Retrieval-Augmented Generation pipeline.

Instead of relying only on a language model, the system first searches relevant college information.

## RAG Workflow

```text
User Question
      │
      ▼
Query Processing
      │
      ▼
Spell Correction / Cleaning
      │
      ▼
Embedding Generation
      │
      ▼
FAISS Similarity Search
      │
      ▼
Relevant Documents Retrieved
      │
      ▼
Cross-Encoder Re-Ranking
      │
      ▼
Relevant Context Selected
      │
      ▼
Groq LLM
      │
      ▼
Final Response
```

### Example

**User:**

```text
What is the hostel fee?
```

The system:

1. Converts the query into a vector.
2. Searches the FAISS knowledge base.
3. Retrieves relevant hostel-related information.
4. Re-ranks the results.
5. Sends relevant context to the LLM.
6. Generates a context-aware answer.

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/CollegeGPT.git
```

Move into the project directory:

```bash
cd CollegeGPT
```

---

## 2️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### macOS / Linux

```bash
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

# 🔐 Environment Variables

Create a `.env` file.

```env
GROQ_API_KEY=your_groq_api_key

RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_key_secret

SECRET_KEY=your_secure_secret_key
```

> ⚠️ Never upload your real `.env` file to GitHub.
